MD-01..06 harness preparation notes (pre-freeze, no acceptance)
================================================================

1) MODULE / DEPENDENCY VERIFICATION (MD-01, MD-06 §5)
-----------------------------------------------------
Once src/CSharp.UI.Markdown exists, external checks runnable from an out-of-repo
console snapshot (same lib-snapshot pattern as rt03-verify):

  - Dependency isolation: `dotnet list src/CSharp.UI.Markdown/CSharp.UI.Markdown.csproj
    package --include-transitive` must list Markdig 1.5.0 and NO transitive deps;
    `dotnet list src/CSharp.UI/CSharp.UI.csproj package --include-transitive` must NOT
    contain Markdig. Save raw stdout both ways.
  - Package identity: after `dotnet pack -c Release` on the Markdown csproj, expand the
    .nupkg (zip) and assert the packed lib folder contains CSharp.UI.Markdown.dll,
    .deps.json references Markdig 1.5.0, and NOTICE/license content expected by MD-05
    ships inside the package (NOT a doc-copy assertion — unzip real artifact).
  - Assembly-level check from harness: load CSharp.UI.dll via reflection and assert
    `Assembly.GetReferencedAssemblies()` does NOT contain "Markdig"; loading
    CSharp.UI.Markdown.dll DOES. This is a real binary dependency-graph probe, not a
    source grep.
  - Cache behavior (public): `Markdown.Parse` returns equal/identical document for
    same (source, options) — compare via object identity or the module's equality
    contract; change one options field (e.g. PipeTables=false) → reparse. Evidence:
    wrap with timing/allocation-free probe or the module's own diagnostic counters
    if exposed; otherwise observable through two Parse calls returning distinct
    instances vs same instance.

  - link interaction → DispatchPointer on link rect activates payload URL (RT-04 path)

    command-text diff)

5) SCENARIO TIERS — which evidence needs real GL pixels vs runtime+Skia suffices
REAL GL (GlOffscreenSurface render + pixel sampling) required for:
    rects (nested "**bold _it_ `code`**" — innermost code font+bg must win
    over emphasis; bold italic both present)
    single style, no doubled ink
    pixels; oversized image aspect-scaled within available width
    visible under horizontal wheel/drag

RUNTIME + REAL SKIA (commands/counters/DesiredSize, no pixels) sufficient for:
    field change → reparse (identity/equality observable publicly)
    rendered commands (or rendered paragraph count)
    (no activation callback on dispatch; activation list empty)
    once OnLinkActivate exists)
    on child nodes — public geometry)
    desired sizes at 320 vs 768 vs 1024 without new parse — cache identity
    unchanged across resize)
    bubbles when none (existing wheel semantics)
