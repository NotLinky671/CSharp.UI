# 输入法手动验收清单

## 证据级别

| 级别 | 含义 | 能证明什么 |
|---|---|---|
| 自动消息回放 | 测试里合成按键或 TSF 事件 | 状态机与写入次数；**不是**真实候选窗口证据 |
| 真实输入法 | 在真实窗口里用实际输入法输入 | 预编辑、候选位置、取消、唯一提交 |

自动测试通过不能替代真实输入法验收；未实际执行的项必须记为“未测”，不能记为“通过”。

## 前置条件

- 控件展示示例（`samples/CSharp.UI.Samples.ControlGallery`）走默认 IMM 路径，“文本编辑与输入法”区域的输入框用于下面的基本输入与撤销重做检查。
- Windows TSF 路径是内部开关 `UseTsfInputBridge`，不是公开选项，入口必须声明 `[STAThread]`。控件展示示例的入口不满足这一点，TSF 的真实验收使用 `tools/CSharp.UI.ImeHostCheck`，而不是示例。
- 已记录的 TSF 验收环境：微软拼音、150% 缩放、单显示器，见 [P4 交付记录](../delivery/2026-10-22-ti07-p4-delivery.md)。其它输入法与 DPI 没有证据。
- macOS 与 Linux 只有已提交文本通道，没有真机输入法证据，见[平台、字体与原生依赖](platform-notes.md)。

## 清单

每项记录：平台、输入法、DPI、结果（通过 / 失败 / 未测）与实际现象。

### 基本输入（控件展示示例）

- [ ] 英文字符输入。
- [ ] 中文输入法上屏后文本正确。
- [ ] 粘贴中文（Windows/Linux Ctrl+V，macOS Command+V）。
- [ ] 选中一段文字后输入，选区被替换。
- [ ] 撤销与重做：Windows/Linux 用 Ctrl+Z、Ctrl+Y、Ctrl+Shift+Z；macOS 用 Command+Z、Command+Shift+Z（macOS 没有 Command+Y）。
- [ ] AltGr 组合键（常表现为 Control+Alt）不触发撤销或重做。

### 窗口与状态变化

- [ ] 组合中切换到其它窗口（失活）：预编辑不被写入文本。
- [ ] 组合中把焦点切换到另一个输入框。
- [ ] 组合中最小化再恢复：恢复后重新输入只提交一次。
- [ ] 外部修改绑定值后，输入框显示同步更新。
- [ ] 输入框所在节点被卸载后，没有残留候选窗口。

### 布局与显示

- [ ] 窗口宽度分别调到 320、480、768、1024 逻辑宽度，“文本编辑与输入法”区域不撑破布局。
- [ ] 拖动窗口边框缩放时，输入框光标位置正确。
- [ ] 页面滚动后候选位置跟随文字（仅 TSF 路径，用 `ImeHostCheck`）。
- [ ] 其它 DPI 下的候选位置：没有证据，记为“未测”。

### 长度与分段

- [ ] `TextField.MaxLength` 限制下，超长输入不产生半个代理项。控件展示示例没有设置 `MaxLength`，此项需要自建带 `MaxLength` 的输入框。
- [ ] 长句分多段上屏，每段只写入一次。

## 验证工具的安全边界

- 验证工具只在测试窗口内读取输入，不记录用户日常输入，不安装全局键盘钩子。
- 关闭窗口后不应遗留窗口或进程；验收后在任务管理器确认没有残留。
