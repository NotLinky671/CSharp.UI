## 目标与范围

让响应式 builder 读取状态后自动更新，并正确管理分支身份、卸载、焦点、捕获和资源。

## 前置依赖

[RL-05](05-responsive-transactions.md) 完成并通过复审；使用其已经固定的契约。

## 实施清单与接口交接

- [ ] 推广内部依赖跟踪目标，Responsive builder 有独立读取作用域；状态通知可区分普通 Component 与响应式内容更新，不能因 View 不是 Component 而丢弃失效。
- [ ] 使用栈式/可恢复的追踪作用域；条件依赖替换、异常、嵌套组件挂载与卸载后都清理订阅，保持既有 UseState 所有权。
- [ ] 禁止 builder 内创建 UseState、同步写状态或借窗口操作触发布局副作用；能够检测的状态写入给出明确异常，IO/外部副作用在公开契约中明确禁止。
- [ ] 只挂载活跃分支；跨父级/类型切换按现有规则卸载，不许隐形保留全部候选树；同父级同Key/类型可复用。
- [ ] 清理移除控件的焦点、捕获、绑定额外依赖和计时；外层State/Binding数据保留，跨父级编辑态迁移不承诺。

## 测试与验收

- [ ] builder 内读取的 State 变化能更新内容，条件读取停止后无残留订阅，卸载节点不再构建。
- [ ] 同父级Key复用保持状态，真正移除分支会卸载并清除交互；外层绑定数据跨分支切换保留。
- [ ] 错误builder、嵌套Responsive与组件、后台Post、短时间多次状态/宽度变化正确合并，缓存/依赖有界。
- [ ] UseState既有全部回归与R18重入/退出回归保留；API文档说明与AdaptiveStack的身份差别。
