## 目标与范围

使用通用 API 让 Gallery 在320/480/768/1024逻辑宽度可用，提供独立嵌套容器示例与迁移指南。

## 前置依赖

[RL-03](03-flow-layout.md)、[RL-04](04-adaptive-stack.md)、[RL-06](06-responsive-state-and-lifetime.md) 完成并通过复审；使用其已经固定的契约。

## 实施清单与接口交接

- [ ] 页头/表单行用AdaptiveStack，按钮组用Flow，输入框和滑块使用横向弹性长度；文本Wrap/Ellipsis以实际可用宽度计算，可保留演示maxWidth。
- [ ] 图片说明、状态文本、修饰符演示都能换行/增高；保留首版全部控件及真实内层ScrollView，不能删除内容来规避窄窗口。
- [ ] 新增可独立实例化的NestedResponsiveExample组件（可在现有示例工程内），在同一窗口宽度下展示宽/窄两种容器响应；独立测试直接实例化它，不复制Gallery树。
- [ ] 稳定身份优先AdaptiveStack，任意Responsive分支示例把持久状态放外层，明确输入焦点边界。
- [ ] 更新根README、API、弹性/Frame顺序、响应式状态身份与迁移指南；新旧两份设计计划及历史任务入口清楚。

## 测试与验收

- [ ] 320/480/768/1024逻辑宽度下主题按钮与主要操作可访问，文本按需换行/省略，没有非预期横向裁切。
- [ ] 相同全局窗口中不同父宽度正确响应；宽窄切换后计数、绑定、内层滚动与稳定输入焦点保持。
- [ ] 示例覆盖所有新增API及首版能力，指南代码可以编译；不向产品界面泄漏诊断/实施细节。
