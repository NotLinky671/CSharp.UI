## 实施清单与接口接入

- [ ] 记录实际OpenTK/GLFW版本、Windows消息顺序、字符来源和线程；核对依赖源码/原生二进制而非最新版文档。
- [ ] 在自有窗口验证IMM32宽接口、WM_IME起止/更新/分段结果与系统候选锚点；判定是否必须TSF，注明消息转发和去重所有权。

- [ ] 把必须复用的最小探针放tools或tests，决策记录写docs/agents-notebook/2026-10-17-ime-platform-decision.md，证据放同前缀-evidence目录。

## 测试与验收

- [ ] 真实微软拼音输入、选词提交一次、取消、候选可定位；记录系统版本/输入法版本、事件时间线和原尺寸证据。
- [ ] 普通英文、补充平面字符、组合结果+后续预编辑同消息，以及失焦/关闭/原生回调异常安全。
- [ ] Codex审核接入路线和降级边界；Windows真实原型不通过则不放行TI-02及后续实现，不以模拟消息代替。
