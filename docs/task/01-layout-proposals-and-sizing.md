## 目标与范围

建立探测/有效测量和固定尺寸传播的内部契约，供伸缩与 Responsive 使用；保持既有布局默认行为。

## 前置依赖

无新增前置任务；基于当前已交付框架与441项测试基线。

## 实施清单与接口交接

- [ ] 在 LayoutContext/ViewNode 测量路径区分 Probe 与有效提案，嵌套作用域以 finally 恢复；不向公开核心 API 暴露后端类型。
- [ ] 测量缓存必须区分提案性质：Probe 后以相同约束进行有效测量仍能登记有效布局提案，不能被缓存跳过；探测不得挂载、卸载或选择 Responsive 内容。
- [ ] 定义内部按轴的布局特征：自然尺寸、明确固定/min/max、Flex 配额、FillWidth。沿 Padding/Frame/普通修饰符传播，明确外层/内层与主轴/交叉轴的归属，不能从被截短的 DesiredSize 推断可压缩性。
- [ ] 提供有节点路径的布局溢出/无界诊断基础；同类稳定问题不逐帧重复刷日志，诊断记录与缓存须有界。
- [ ] 保留未启用新能力的 HStack/VStack/Spacer/Frame 和修饰符顺序；在本任务文末记录供后续任务使用的内部契约。

## 测试与验收

- [ ] 相同约束 Probe→有效测量、嵌套探测与异常退出均正确；有效提案不会被 Probe 覆盖。
- [ ] 固定宽度包在 Padding、Frame、普通修饰符内仍能正确识别；小数、零和无界约束无 NaN/无穷几何泄漏。
- [ ] 现有布局/状态测试不退化；新增行为测试而非仅检查 helper 字段值。
