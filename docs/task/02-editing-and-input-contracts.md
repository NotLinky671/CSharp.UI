## 目标与范围

冻结平台无关数据、焦点会话和宿主处理结果，保留现有应用API。

边界：契约和值类型、服务替身；不提前实现平台消息桥。

## 前置依赖

[TI-01：平台可行性与 Windows 原型](01-platform-feasibility.md)接入路线已通过Codex审核。按2026-10-17用户修订，微软拼音不测试；原生候选与取消验收移交TI-07/TI-10，不阻塞平台无关契约实施。

## 实施清单与接口接入

- [ ] 定义选区方向、UTF-16范围与字素处理、版本、EditOperation/Result、CompositionUpdate和明确事件顺序；与计划第5至7节一致。
- [ ] 设计ITextInputClient/Service、分项能力查询、默认已提交文本回退及依赖注入；原生类型不进入核心。
- [ ] 给文本会话建立焦点epoch/组合ID/版本和同步Handled结果，定义取消确认与过时数据处理。
- [ ] 冻结Binding来源识别、setter回读、同值重建、MaxLength变更及历史配置契约；API草案须经Codex审核后使用。

## 测试与验收

- [ ] 核心程序集无OpenTK/Skia/平台依赖；旧TextInputEvent/TextField构造用法编译不变。
- [ ] 范围越界、负值、无效次序/会话、空预编辑与无能力服务有明确可测行为。
- [ ] 记录实际公开/内部签名与变更原因，避免只为测试公开节点内部编辑状态。
