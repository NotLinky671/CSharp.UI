## 目标与范围

建立不可变视图描述树与持久运行时节点树，允许重复声明 UI 而稳定复用对应节点。

本任务实现身份、组合和生命周期；状态依赖由任务 04 实现，焦点与滚动系统后续接入节点生命周期。

## 前置依赖

- 前置任务：[任务 02：平台无关基础类型与服务契约](02-core-contracts.md)。
- 接入依据：使用任务 02 的核心值类型、服务契约和测试替身。

## 实施清单

- [x] 实现 View 描述与 Component，通过受保护的 Build() 返回描述树；描述对象与可变运行时节点分离。
- [x] 支持组合子视图、普通 C# 条件内容、Key 修饰和带键 ForEach；描述变更产生新对象，不原地修改已有描述。
- [x] 未指定 Key 时按类型与结构位置匹配；指定 Key 的同级节点按 Key 和类型匹配，更新属性、子项及事件处理器。
- [x] 运行时节点拥有可附加的状态、交互状态及资源生命周期；同一身份节点重用，类型替换或移除时卸载。
- [x] 提供挂载、更新、卸载流程，清理节点持有资源；对同级重复 Key 给出明确诊断，避免静默串用状态。
- [x] 用无窗口测试验证插入、删除、重排、条件切换和事件更新，为任务 04 的命名状态存储留出节点位置。

## 公开 API 与交接

交付 View、Component.Build()、Key 和 ForEach；运行时节点及协调更新细节不作为应用侧直接操作 API。

交付实现、对应测试及必要使用说明；所有测试与实现同步完成。后续任务消费本任务契约时保持原计划的模块边界。

## 测试与验收

- [x] 相同类型与身份的节点保持同一个运行时实例；变化的属性及事件回调及时替换，不执行旧回调。
- [x] 带键列表插入、删除、重排时节点附加状态跟随原项目；不同类型即使 Key 相同也正确替换。
- [x] 条件分支替换和组件卸载触发一次清理；删除节点后无存活的资源引用或事件处理器。
- [x] 描述树可重复使用且不因协调更新被修改；重复 Key 情况能被定位和解释。
