## 实施清单与接口接入

- [ ] 实现每节点undo/redo栈、100条及1,048,576 UTF-16保留量双上限、完整事务淘汰和超大单项策略。
- [ ] 实现500ms单调时钟合并，仅合并同源相邻键入/同向删除；剪贴板/组合结果/选区/焦点/外部更新打断。
- [ ] Undo/Redo前取消预编辑，再经统一事务写Binding，恢复前后选区方向并滚动可见；新编辑清redo。
- [ ] 添加平台正确快捷键映射，保留AltGr和IME优先级；宿主最终路由在TI-07接通。
