## 实施清单与接口接入

- [ ] 提取文档、选区、版本与原子替换模型，TextField普通键入/删除/剪贴板全部接入；选择移动不制造文本事务。
- [ ] 保持UTF-16 MaxLength、选区释放容量与完整字素截断；保留既有单行净化规则。
- [ ] 捕获快照、写Binding一次并回读确认，处理拒绝/规范化/抛错；外部写入、来源替换与自身确认可靠区分。
- [ ] 同节点同绑定重建/Flow/Adaptive布局保持编辑状态；外部文本与配置变更按计划清理并限制选区。

## 测试与验收

- [ ] 表驱动或确定性随机序列覆盖真实编辑状态，不仅测试helper；代理对、组合附加符、ZWJ与选区方向。
- [ ] 粘贴替换、空串/全拒绝/边界删除、MaxLength、setter拒绝/转换/异常不污染文档版本。
- [ ] 运行旧TextField/Binding/响应式输入回归；文字caret与横向滚动保持。
