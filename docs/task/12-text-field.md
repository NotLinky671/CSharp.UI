## 目标与范围

提供可绑定字符串的单行输入框，正确处理字素边界、选择、剪贴板与光标可见性。

支持宿主提交的 Unicode 文本和中文粘贴；不实现多行编辑、完整 IME 组合文本或候选窗定位。
