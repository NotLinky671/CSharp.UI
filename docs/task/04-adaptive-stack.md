## 目标与范围

根据父级有效逻辑宽度切换横向/纵向布局，避免更换容器类型导致控件重新挂载。

## 前置依赖

[RL-02](02-flex-and-fill-width.md) 完成并通过复审；使用其已经固定的契约。

## 实施清单与接口交接

- [ ] 实现 AdaptiveStack(breakpoint, params View[] children)，正有限断点，width<断点为纵向、width>=断点为横向；无界宽度为横向自然尺寸。
- [ ] 复用统一 Stack 测量/排列算法，支持两种模式分别配置间距和交叉轴对齐；默认语义与对应 HStack/VStack 一致。
- [ ] 父节点类型与同级子项集合稳定，只改变布局策略，不通过 HStack/VStack 树替换实现。
- [ ] 正确解释 FlexAxis.Main 与显式水平/垂直参数，说明 Spacer 在有限/无限主轴的行为；更新模式变化的测量缓存。

## 测试与验收

- [ ] 断点精确值、两侧小量、小数宽度、嵌套约束及 DPI1/1.25/1.5/2 下模式正确。
- [ ] 输入中文、选择文本、设置焦点后宽→窄→宽，TextField/Component/滚动节点身份及交互状态保持。
- [ ] 同模式连续宽度变化仅重新布局，不卸载子项；无界与硬尺寸溢出有明确结果。
