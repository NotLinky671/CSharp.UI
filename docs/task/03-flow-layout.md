## 目标与范围

提供确定性的横向自动分行，维持同一批子节点、绘制顺序和交互身份。

## 前置依赖

[RL-02](02-flex-and-fill-width.md) 完成并通过复审；使用其已经固定的契约。

## 实施清单与接口交接

- [ ] 实现不可变 Flow、Spacing/LineSpacing 与行内顶部/Center/End 对齐，采用从左到右的贪心分行；行高由最终测量后的最高项目决定。
- [ ] 空项、正好放满、无界宽度、单项超宽都有明确行为；可重新测量的项限制到整行宽度，不可压缩固定项独占一行并诊断。
- [ ] 不用每行额外运行时容器重挂载子项；只保存有界布局缓存并更新 Frame，Key 与声明顺序保持。
- [ ] 首版不做逐行 Flex 权重分配，直接子项的 Flex grow/shrink 给出不支持诊断；FillWidth 作为整行宽度请求处理，不能按逐行权重分配。
- [ ] 垂直 ScrollView 中自然高度正确；宽度收缩/展开使内容高度和滚动边界更新。

## 测试与验收

- [ ] 分行的几何、换行阈值、行高、间距和多行文字用真实布局断言，包含 Padding/Border。
- [ ] 换行前后 Key 节点实例、组件状态、TextField 焦点/选择与 Tab 顺序保持；旧坐标不能命中。
- [ ] 窗口宽度相同但嵌套容器宽度不同会产生不同分行；无界时为单行，极窄时无死循环。
