## 目标与范围

预编辑不写Binding，分段结果只确认一次，过时或结束的会话不能串写新节点。

边界：核心状态机和模拟服务；原生消息接入由TI-07完成。

## 前置依赖

[TI-03：统一编辑事务与 Binding 同步](03-atomic-editing-and-binding.md)均须Codex复审通过后再实施；使用前置任务已冻结契约。

## 实施清单与接口接入

- [ ] 实现Start/Update/Result/Cancel及重复End幂等，保留每段原替换区/选区、显示串到文档映射。
- [ ] 处理结果+下一段预编辑同一事件批次、分段提交后重新定位；取消仅丢弃未提交段。
- [ ] 实现焦点/禁用/卸载/窗口失活/外部绑定变更等取消规则和旧epoch事件隔离；同节点布局不取消。
- [ ] 定义组合期间编辑命令、鼠标改选区、复制及Tab/Enter/Escape所有权接口，不能在unsafe回调里递归布局。

## 测试与验收

- [ ] 长预编辑不写绑定、结果按MaxLength完整字素接受、一次结果只产生一次事务。
- [ ] 结果/结束乱序、重复/过时事件、无Start的合法平台序列、分段结果及切焦点同步回调。
- [ ] 外部修改/来源替换/真正卸载清理，Responsive重建与Adaptive保持场景按各自语义验收。
