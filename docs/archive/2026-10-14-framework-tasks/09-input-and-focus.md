## 目标与范围

把平台输入转换成稳定的视图交互，支持鼠标、键盘、滚轮及组件更新后的交互状态保持。

实现通用输入与焦点基础；控件行为由任务 10、11、12 接入，不实现 IME 组合输入。

## 前置依赖

- 前置任务：[任务 05：布局、修饰符与绘制命令生成](05-layout-and-modifiers.md)、[任务 06：OpenTK 桌面宿主与按需事件循环](06-opentk-host.md)。
- 接入依据：使用任务 05 的布局、层叠与有效裁剪，任务 06 的输入来源；接入任务 03 的节点卸载机制。

## 实施清单

- [x] 把 OpenTK 指针、滚轮、键盘和已提交 Unicode 文本转换成核心事件，统一逻辑坐标与修饰键。
- [x] 依据布局和逆绘制顺序命中测试，过滤不可见、被裁剪及禁用目标；维护悬停与按下状态。
- [x] 实现指针捕获，允许按下后移出控件继续拖动；目标卸载、窗口失焦时清理捕获及按下状态。
- [x] 建立焦点管理与 Tab/Shift+Tab 遍历，更新保留相同节点的焦点；节点删除或禁用时转移或清除焦点。
- [x] 为控件提供键盘激活、已提交文本和滚轮分发入口；按事件处理结果路由，避免同一输入被多个目标重复消费。
- [x] 实现核心 Disabled 标记与继承的交互过滤，为任务 10 的视觉反馈和任务 13 的环境机制提供接入。

交付平台无关输入事件和控件交互接入点；Disabled 修饰符影响命中、焦点及键盘处理。
