## 目标与范围

在具体实现前定义跨模块契约，让布局、文本、输入和渲染通过核心类型协作。

交付最小可用契约和测试替身；具体节点更新、测量、排版及 GPU 操作由后续任务实现。

## 实施清单

- [x] 定义逻辑坐标、尺寸、矩形、内边距、颜色和字体描述，明确逻辑像素与 framebuffer 像素的转换边界。

## 公开 API 与交接

公开应用需要的颜色、几何、字体描述与配置类型；跨模块服务契约只包含框架类型和 .NET 基础类型，不暴露 OpenTK、SkiaSharp 或原生指针。

交付实现、对应测试及必要使用说明；所有测试与实现同步完成。后续任务消费本任务契约时保持原计划的模块边界。
